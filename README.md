# OpenAnalyst Plugin Releases

Public release downloads for the [OpenAnalyst](https://openanalyst.com) plugin suite.

This repository exists **only to host signed release assets** so anonymous users can download installable plugin zips. The actual plugin source code lives in the private [`10xDotIn/Openanalyst-Plugins`](https://github.com/10xDotIn/Openanalyst-Plugins) repository.

## Available plugins

| Plugin | Latest | What it does |
|---|---|---|
| Meta Ads Plugin | [v1.0.0](https://github.com/10xDotIn/Openanalyst-Plugin-Releases/releases/latest) | Connect Facebook & Instagram campaign metrics directly to your OpenAnalyst workspace |

## How to install

1. Download the `.zip` from the [Releases](https://github.com/10xDotIn/Openanalyst-Plugin-Releases/releases) page.
2. Open OpenAnalyst → **Settings** → **Plugins** → **Install from file**.
3. Select the downloaded zip and confirm.

See [links.10x.in/meta](https://links.10x.in/meta) for the full setup walkthrough.
